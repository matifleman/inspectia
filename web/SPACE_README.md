# InspectIA

Visual surface-defect inspection (KolektorSDD2) with a fine-tuned ResNet18 + Grad-CAM.
The model runs **in your browser** (ONNX Runtime Web): the image never leaves your device.
The dataset is not redistributed here: upload your own image.

Code and report: https://github.com/matifleman/inspectia
