# InspectIA

Visual surface-defect inspection (KolektorSDD2) with a fine-tuned ResNet18 and Grad-CAM.
Upload a part image: you get the defect probability, a verdict (DEFECTUOSA / REVISAR / OK) and
a heat map. The dataset is not redistributed here: upload your own image.

Code and report: https://github.com/matifleman/inspectia
